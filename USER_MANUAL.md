# Zentra — Application User Guide

*The complete manual for event managers, sales staff, operations teams, and administrators.*

## 1. Introduction

### 1.1 Purpose of the Application

Zentra helps your event business manage the complete journey of an event
— from the first client enquiry to final profit review — in one place.

You can use it to record enquiries, maintain clients and vendors,
prepare estimates, manage estimate versions, create events, handle extra
requirements, plan work with checklists, purchase from vendors, track
money, keep stock organised, and manage staff accounts.

Everything is connected: an enquiry becomes an estimate, an approved
estimate becomes an event, the event drives your checklist and
purchasing, and all of this feeds into your financial summary.

### 1.2 Who Should Use This Guide

- **Sales team** — enquiries, estimates, sending quotations to clients
- **Event managers** — events, checklists, vendor coordination
- **Operations / purchase team** — purchase orders and vendor work
- **Finance / owners** — billed amounts, balances, costs, and profit
- **Administrators** — clients, vendors, inventory, and staff users

No prior experience with the application is needed.

### 1.3 Application Overview

Main areas in the left-side menu:

**Overview**

- Dashboard — greeting, summary cards, calendar, shortcuts

**Sales**

- Enquiries — incoming event requests
- Clients — client contact and billing details

**Operations**

- Estimates — quotations and all versions

- Schedules — currently “Coming Soon”

## 2. Getting Started

### 2.1 Logging In

1. Open the login screen.
2. Enter your User ID and Password.
3. Click Login.
4. You will be taken to the Dashboard.

Other points:

- Wrong details show a red error message. Check and try again.
- Use Show / Hide to see your typed password.
- Forgot password: click “Forgot your password?”, enter email,
  enter the 6-digit code, enter and confirm the new password,
  then Back to Login.
- Google login button is shown but only use the User ID login
  given by your administrator for daily work.

### 2.2 Understanding the Main Screen

Every working screen has:

- Top bar: logo, bell Notifications icon, a theme switch (desktop),
  and your profile avatar. Clicking the avatar opens Profile,
  Settings, Change Password, and Log out.
- Left menu: grouped sections listed above.
- Main area: title, description, action buttons, table or cards,
  search/filter and pages where needed.

### 2.3 Navigation

- Click a menu item to move sections.
- Click a table row or View to see details.
- Use Close / Cancel to return without saving.
- On mobile, use card buttons View, Edit, Delete, Versions, Clone.
- You only see sections allowed for your role.
- Dashboard Quick Actions include Create Enquiry, New Estimate,
  Book Event, Generate Bill, Add Client, View Reports. Some may
  lead to “Coming Soon” pages; use the left menu for daily work.
- Clicking the logo returns you to the public home page.
- The theme switch cycles Light, Dark, and System appearance (also
  available in the mobile menu under Theme).

## 3. Application Workflow

Normal business flow:

```text
New Enquiry
   ↓
Client record
   ↓
Estimate Version 1, 2, ...
   ↓
Send → Review → Approve / Final
   ↓
Create Event
   ↓
Checklist
   ↓
Purchase Orders
   ↓
Billing and Expenses
   ↓
Profit Summary
```

Extra requirements after event creation:

```text
Client asks for more items
   ↓
Additional Estimate
   ↓
Compare → Confirm and Save
   ↓
Approve / Final → Merge into event
   ↓
Checklist and Purchase Order update
```

## 4. Enquiries

### Purpose
Enquiries record every new event request: who asked, what they want,
when and where, and who is handling it.

### When to use it
Use for every new client request and to track existing requests.

### How to use it
1. Go to Enquiries.
2. Search, filter by Status, or sort if needed.
3. Click Create Enquiry.
4. Fill the form and click Save Enquiry.
5. Click a row to open the detail view.
6. From the view use Edit, Delete, Clone, Create Estimate,
   View Estimate, or View Event.
7. Use Export to download the list.

### Fields
| Field | What it means | What to enter |
| ----- | ------------- | ------------- |
| Client | Who the event is for | Select client or type new name |
| Event Title | Working name | Clear name, 3+ letters, required |
| Event Type | Nature of event | Personal, Corporate, Other, required |
| Location | General area | Required |
| Venue | Exact place | Required |
| From / To Date | Event period | End must not be before start |
| High Level Requirements | Client needs | Required summary |
| Client POC | Client person | Name if known |
| Client POC Contact Number | Client phone | Required |
| Event POC | On-site contact | Name if known |
| Enquiry POC | Sales owner | Name if known |
| Event POC Number | Event-day phone | Digits, up to 10 |
| Assigned To | Handler | Staff name |

### Actions
Create Enquiry, Save Enquiry, Edit, View, Delete, Clone,
Create Estimate, View Estimate, View Event, Export, Close.

### Result
Saving adds the row and opens details. Create Estimate carries
client, dates, venue, and requirements forward. View Event shows
only after the event exists.

## 6. Estimates

### Purpose
An estimate is your quotation: items, quantities, days, rates,
taxes, service charge, discount, and extra costs.

### When to use it
Create one as soon as an enquiry has enough detail. Revise with
new versions until the client agrees.

### How to use it
1. Go to Estimates or start from enquiry Create Estimate.
2. Click Create Estimate.
3. Check Client and Enquiry/Title.
4. Enter dates, venue, location, contacts.
5. Add Categories, Sub Categories, Items.
6. For each item enter Item, Specification, Days, Quantity,
   Unit, Rate, Vendor.
7. Add Additional Costs, GST/Tax Type, Service Charge, Discount,
   billing details.
8. Review Cost Summary.
9. Save Estimate.
10. Use Preview, Download, Send, Clone, Versions as needed.

### Key fields
| Field | What to enter |
| ----- | ------------- |
| Category / Sub Category | Group names |
| Item | Required name |
| Specification | Clear details |
| Days | 1 or more |
| Quantity | 1 or more |
| Unit | nos, pcs, sqft, etc. |
| Rate | Amount above zero |
| Vendor | Supplier name if known |
| Additional Costs | Item, amount, remarks |
| GST / Tax Type | Percent and No GST / CGST+SGST / IGST |
| Service Charge | Percent/amount as shown |
| Discount | Amount |
| Billing Address | Full bill-to address |
| Terms and Conditions | Required before download/email |

Each item amount is Quantity x Rate x Days. Service charge,
discount, GST, and additional costs adjust the final total.
GST applies after service charge and discount.

### Actions
Create, Save, Edit, Delete, Clone, Preview, Download PDF/Excel,
Send Email, Mark Under Review, Approve/Final, Versions,
Additional Estimate, Create Event, Export, Close/Cancel/Back.

### Result
Saved estimates appear in Estimates and Versions. The preview
table columns are Sl. No, Elements, Details, nos, Rate, and
Amount, followed by subtotals and the grand summary. Terms and
Conditions appear on the preview and are required before download
or email. The preview offers Download PDF and Download Excel.

## 7. Estimate Approval and Versions

### Purpose
Versions let you revise a quotation without losing history.
Only one version becomes the final basis for the event.

### When to use it
Open Versions whenever a client asks for changes or you need to
compare options.

### How to use it
1. In Estimates, click Versions for the enquiry.
2. Expand a version to see items.
3. Use Preview, Edit, Clone, Email, Delete.
4. Click Send to Client to email the version; this also moves it to
   Under Client Review.
5. When the client agrees, click Mark as Final. You can Revert to
   Draft if changes are needed.
6. For extra needs after event creation, use Additional Estimate.
7. Use Create Event only from the approved/final version.

Version labels you will see include Draft, Under Client Review,
Final, Event Created, Event Merged. Status names include Enquiry
Created, Estimate In Progress, Estimate Under Review, Estimate
Approved, Project In Progress, Project Settlement In Progress,
Project Completed, Checklist Completed, Project Postponed.

### Result
Approving locks the commercial basis. Create Event becomes
available. Event Created/Final status prevents confusion about
which quotation is valid.

## 8. Event Management

### Purpose
Events are confirmed work. An event carries forward the approved
items, client, dates, venue, taxes, and totals into execution.

### When to use it
Create an event only after the client approves a version.

### How to use it
1. From approved estimate Versions, click Create Event.
2. Or go to Events and click Create Event, then select the
   approved Estimate, Client, Title, dates, location, venue.
3. Click Create Event / Update Event.
4. Open the event from Events by clicking View or the title.
5. At the top of the event you will see its status badge, date,
   title, location, money cards (Estimated Cost, Total Income,
   Total Expense, Pending, Current Balance), and the Edit Project
   and Approve Event buttons.
6. Use the expandable detail cards: Client Details, Event Details,
   Estimate History, Event Checklist, Inventory List, Purchase
   Order, Expenses, and Billing & Tax.
7. Estimate History lists earlier versions with their items and
   amounts. The Event Checklist card opens Checklist Preview; the
   Purchase Order card opens the order editor and preview.
8. Use Edit, Clone, Delete, Export in the Events list as needed.

### Fields
| Field | What to enter |
| ----- | ------------- |
| Title | Event name, required |
| Estimate | Approved estimate, select from list |
| Client | Select client |
| Event Start / End Date | Start required; end after start |
| Location / Venue | Where it happens |

### Result
The event appears in Events and calendar. Its items feed the
checklist, purchase orders, billing, and profit. Clone copies an
event. Delete removes it after confirmation.

## 9. Additional Estimates

### Purpose
An additional estimate records extra client needs after the event
is already created, without disturbing the original approved event.

Example: client adds 20 chairs after approval. Record them in an
additional estimate, approve it, and merge it into the live event.

### When to use it
Use only after an event exists and the client asks for additions
or changes.

### How to use it
1. Open Versions for the enquiry/event.
2. Click Additional Estimate on the Event Created version.
3. The form opens with client, event, tax, and old items shown.
4. Add/edit new items as usual.
5. Click Save; a comparison window opens.
6. Review Existing Finalized Event Items vs New Additional Items.
7. Check badges: New Item, Exact Match, Quantity Changed,
   Modified Item.
8. Read each warning message carefully.
9. Click Confirm and Save.
10. Approve / Mark as Final, then Merge into the event.

### Comparison meaning
- New Item: completely new; will be added on merge.
- Exact Match: same item and quantity already exists; duplicate.
- Quantity Changed: same item, only quantity differs; the extra
  quantity is added to the existing item on merge.
- Modified Item: same name but Specification, Days, or Rate
  differs; it will be treated as a new separate item on merge.

### Result
After merge, the version shows Event Merged, and the event
checklist and purchase data include the new items. The original
approved items remain unchanged except for quantity additions.

## 10. Checklist

### Purpose
The checklist is your day-to-day execution plan: what is needed,
how much, when, who supplies it, and whether it is done.

You can open it from CheckLists menu or inside Event Details
through Checklist Preview and Update Checklist.

### When to use it
Prepare it right after event creation and update it during
planning and execution.

### How to use it
1. Open Event Details.
2. Open Checklist Preview to review.
3. Click Update Checklist to edit.
4. Browse Category > Sub Category > Items.
5. Select an item to edit details.
6. Add Category, Sub Category, or Item as needed.
7. Set dates, vendor/stock, status, quantity, unit.
8. Save Checklist.
9. Reopen Preview or Export Preview to verify/download.

### Fields and required items
Required: Item Name, Description, Status, Days, Quantity, Unit.
Optional: Category, Sub Category, Vendor, Inventory, Start Date,
End Date, Deadline Date, Use Inventory switch.
Statuses: Pending, In Progress, Completed.

### Result
Saving updates event items used by purchase orders. If some items
have no vendor/stock, a confirmation lists them; you can still
save and assign later. Export Preview offers PDF/Excel download.

## 11. Vendors

### Purpose
Vendors are suppliers/service providers. Their record holds
contact, billing, tax, and usual items/prices.

Do not confuse vendors with clients. Clients pay you; you pay
vendors.

### How to use it
1. Go to Vendors.
2. Click Add Vendor.
3. Enter Name, Billing Address, GST %, TDS %, GST Certificate,
   Phone, and Items table if known.
4. Click Add Vendor.
5. Use View for details and items, Delete to remove, Export to
   download.

### Fields
| Field | What to enter |
| ----- | ------------- |
| Name | Required |
| Billing Address | Required |
| GST % | 0-100, required |
| TDS % | 0-100, required |
| Phone | Exactly 10 digits, required |
| Items | Item name required, Count 1+, Price 0+, Description optional |
| GST Certificate | Optional |

### Result
Vendor becomes available in checklist and purchase order
selections.

## 12. Purchase Orders

### Purpose
Purchase orders organise what you buy/hire per vendor: items,
quantities, rates, taxes, advances, and balances.

Open from Event Details via Add Purchase Order / View Purchase
Order and the Purchase Order Preview.

### When to use it
Create after the checklist is broadly ready and you know
vendor-wise needs.

### How to use it
1. Open the event and click Add Purchase Order.
2. Review Client Details: name, event, description, estimated
   amount, Service Charge, Tax Type, GST %, Discount, TDS %,
   Received Amount, Billing Address.
3. Select a vendor tab on the left, including Self for your own
   stock.
4. Review categories/items for that vendor.
5. Adjust quantity, rate, days, unit where allowed.
6. Set vendor GST Type/%, TDS %, Advance, Note.
7. Save.
8. Open Purchase Order Preview for category breakdown,
   vendor-wise financial summary, consolidated summary, and
   profit summary.

### Financial fields
- Quantity, Rate, Days drive each line amount.
- GST % and Tax Type: No GST, CGST + SGST, IGST.
- TDS %: amount deducted as shown.
- Advance: already paid to vendor.
- Balance: remaining payable as shown.
- Adjusted Amount: correction if shown.
- Total Amount: vendor total with tax adjustments.

### Result
Preview shows Meta Header, Payment Terms, Category tables,
Vendor Financial Summary, Consolidated Summary, and Profit
Summary for admins. This is your buying and payable control.

## 13. Payments and Balances

Track in two places:

- Client side: Received Amount in purchase Client Details and
  Advance Amount in Billing details; Balance/Outstanding is the
  billed total minus received/advance.
- Vendor side: Advance paid and Balance payable per vendor in
  purchase order and category summaries.

Update advances/received amounts promptly so balances stay correct.

### Project Planning, Expenses, and Billing & Tax details

Inside Event Details you will also see:

- Project Planning: item rows with category, vendor/stock choice,
  quantity, price, days, dates, description, and additional costs.
  It also has a Send to client action that opens a proposal preview
  and a Gmail-style email draft (To, CC, Subject, Body).
- Expenses: Item Name, Amount, Type (Estimated/Actual), Status
  (Estimate Submitted/Approved/Rejected), Person, Comments.
  Only complete rows with name and amount above zero are saved.
- Billing & Tax / Billing Details: Billing Address, PAN, GST %,
  TDS %, Service Charge, Advance Amount, Discounts. Save Billing
  Details updates the event billing used in summaries.



## 14. Cost Summary

Cost Summary appears in estimate and purchase screens as a total
bar with an expandable breakdown. Click the arrow to see items,
then totals. It shows how item lines, additional costs, service
charge, discount, GST/TDS build the final amount.

## 15. Profit Summary

Shown in Purchase Order Preview for admins as internal P and L.

Rows you will see:

| Metric | Meaning | How to interpret |
| ------ | ------- | ---------------- |
| Estimated amount | Approved item + additional cost base | Starting revenue base |
| Service Charge | Fee on base | Extra client billing |
| Discount | Reduction | Lowers taxable amount |
| GST | Tax on taxable amount | Added to bill |
| TDS Deducted | Client deduction | Reduces cash received |
| Total Client Billed Amount | Taxable + GST - TDS | Total bill |
| Client Billed without GST | Bill minus GST | For profit comparison |
| Profit | Revenue left after vendor costs | Positive is good; red/negative is loss |
| Net Hand | Cash effect as shown | Money position after vendor payables |

Vendor GST/TDS feed vendor net costs. Additional estimates are
included once merged. Ask finance/admin if a figure looks wrong;
do not edit profit directly.

## 18. Important Rules to Remember

1. Start from Enquiry; do not create an event first.
2. Only an approved/final estimate creates an event.
3. Use Versions for revisions; history is preserved.
4. Additional Estimate only after event creation; then
   Confirm and Save, Approve/Final, Merge.
5. Quantity Changed adds quantity; Modified Item adds a new line;
   Exact Match is a duplicate.
6. Checklist requires Item, Description, Status, Days, Quantity,
   Unit. Vendor/stock can be added later.
7. Clients pay you; vendors are paid by you.
8. Every Delete needs confirmation and cannot be undone.
9. Terms and Conditions required before estimate download/email.
10. Profit Summary is view-only and admin-visible.
11. Schedules, Expenses, Bills, Reports are not active yet.

## 20. Frequently Asked Questions

- What is an enquiry? A recorded client event request and the
  starting point.
- What is an estimate? A quotation with items, taxes, totals.
- Multiple estimates for one enquiry? Yes, as versions.
- Which estimate creates an event? Only approved/final version.
- After approval? Create Event becomes available.
- When additional estimate? Only after event creation for extra
  needs.
- What does Merge do? Adds approved extra items/quantities into
  the live event, checklist, and purchase data.
- What is checklist for? Execution plan and tracking.
- Client vs vendor? Client pays you; vendor is paid by you.
- Purchase order vs checklist? Checklist is what is needed;
  purchase order is vendor-wise buying and payables.
- Outstanding balance? Billed/reported total minus
  received/advance.
- Where is profit? Event Details > Purchase Order Preview >
  Profit Summary, admin-visible.
- Why cannot download estimate? Enter Terms and Conditions first.
- Why no vendor/stock warning? Informational; save and assign later.
- Bills/Expenses/Reports? Currently Coming Soon; use Export.
